Instruction Set Architecture For My 8 bit pc
By Rasmus Koch Jensen


| Opcode | Instruction | Lower 4 bits         |
| ------ | ----------- | -------------------- |
| `0000` | LOAD        | destination register |	Data movement
| `0001` | STORE       | source register      |
| `0010` | ADD         | options              |	Arithmetic
| `0011` | SUB         | options              |
| `0100` | AND         | options              | Logic
| `0101` | OR          | options              |
| `0110` | XOR         | options              |
| `0111` | NOT         | options              |
| `1000` | SHL         | options              | Bit manipulation
| `1001` | SHR         | options              |
| `1010` | JMP         | unused               | Control flow
| `1011` | JZ          | register/condition   |
| `1100` | JNZ         | register/condition   |
| `1101` | OUT         | register             | Input/output
| `1110` | IN          | destination register |
| `1111` | HALT        | unused               | Halt

ALU flags updates

ZERO:
1 when result = 00000000

NEGATIVE:
1 when result bit 7 = 1

CARRY:
Carry output from the ALU



ADD   -> updates flags
SUB   -> updates flags
AND   -> updates flags
OR    -> updates flags
XOR   -> updates flags
NOT   -> updates flags
SHL   -> updates flags
SHR   -> updates flags

FLAGS register:

bit 2 = ZERO
bit 1 = NEGATIVE
bit 0 = CARRY




Example of program:

LOAD A, address

Cycle 1: Fetch instruction
Cycle 2: Increment PC
Cycle 3: Fetch address
Cycle 4: Increment PC
Cycle 5: Read RAM
Cycle 6: Store into A


T0: IR <- ROM[PC]
T1: PC <- PC + 1
T2: Address Register <- ROM[PC]
T3: PC <- PC + 1
T4: MDR <- RAM[Address Register]
T5: A <- MDR
